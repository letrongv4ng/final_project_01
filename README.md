# Simple Interest Calculator

A simple Interest Calculator is a tool that helps calculate the simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula
Simple Interest is calculated using the following formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount
* **R** = Annual rate of interest (%)
* **T** = Time period (in years)

## Usage
Input the principal amount, interest rate, and time period when prompted to receive the calculated interest output.
